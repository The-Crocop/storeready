StoreReady Cloud

Cloud adds memory to the local scanner: release history, approved baselines, team workflows and eventually store integrations.

The artifact stays local

StoreReady scans the IPA/AAB on the developer machine or CI runner. The current Cloud contract receives normalized release metadata rather than the binary itself.

Approve a release

After Apple or Google approves an exact release artifact, record it as the baseline for that project and platform:

export STOREREADY_CLOUD_URL=http://localhost:8080
export STOREREADY_API_KEY=local-dev-key

storeready approve \
  --project mobile-app \
  MyApp-2.3.0.ipa

Push the next release

storeready push \
  --project mobile-app \
  MyApp-2.4.0.ipa

The CLI fetches the latest approved baseline automatically, applies the diff locally, then uploads the normalized scan result.

What is currently sent

  • Artifact filename
  • SHA-256 of the artifact
  • Platform
  • Passed / warning / blocker counts
  • Detected privacy-sensitive permission signals
  • Detected SDK signals

What is not currently sent

  • The IPA or AAB binary
  • Your source code
  • Signing certificates or provisioning keys

Alpha status

Cloud is under active development. The current development API key is an alpha mechanism. Production SaaS authentication will use user sign-in plus scoped, revocable CI tokens.
