TRUST

Privacy

The open-source StorePreflight CLI can be used without a StorePreflight account or Cloud connection.

Local CLI

Local scan and baseline commands inspect files on the machine where StorePreflight runs. They do not require StorePreflight Cloud.

Cloud-enabled commands

When a user explicitly configures StorePreflight Cloud and runs push or approve, the current API sends normalized release metadata such as artifact filename and SHA-256, platform, readiness counts, permission signals and SDK signals.

Application binaries

The current Cloud flow does not upload the IPA/AAB binary itself.

Source code

StorePreflight does not need application source code for artifact scanning.

Future services

StorePreflight Cloud is under active development. This page will be expanded before public commercial availability to describe account data, retention, subprocessors, billing data and user rights.
