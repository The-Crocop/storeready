TRUST

Privacy

The open-source StoreReady CLI can be used without a StoreReady account or Cloud connection.

Local CLI

Local scan and baseline commands inspect files on the machine where StoreReady runs. They do not require StoreReady Cloud.

Cloud-enabled commands

When a user explicitly configures StoreReady Cloud and runs push or approve, the current API sends normalized release metadata such as artifact filename and SHA-256, platform, readiness counts, permission signals and SDK signals.

Application binaries

The current Cloud flow does not upload the IPA/AAB binary itself.

Source code

StoreReady does not need application source code for artifact scanning.

Future services

StoreReady Cloud is under active development. This page will be expanded before public commercial availability to describe account data, retention, subprocessors, billing data and user rights.
