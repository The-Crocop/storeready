CLI commands

Flags must appear before the artifact path.

storeready scan

Scan an IPA or AAB locally.

storeready scan [flags] <artifact.ipa|artifact.aab>
--formattext, json, markdown or sarif
--outputWrite report to a file.
--baselineCompare against a local baseline JSON.
--fail-on-warningReturn exit code 1 when warnings are present.

storeready baseline

Create a local baseline from an artifact without blockers.

storeready baseline --output approved.json MyApp.ipa

storeready push

Scan locally, optionally compare with the latest Cloud baseline, then upload normalized findings.

storeready push --project mobile-app MyApp.ipa
--projectRequired Cloud project key.
--urlCloud URL or STOREREADY_CLOUD_URL.
--api-keyCloud token or STOREREADY_API_KEY.
--baselineUse a local baseline instead of Cloud.
--no-cloud-baselineSkip approved-release comparison.

storeready approve

Record an artifact as the latest approved baseline for a project/platform.

storeready approve --project mobile-app MyApp-2.3.0.ipa

storeready version

storeready version

Exit codes

CodeMeaning
0No blocker. Warnings allowed unless strict mode is enabled.
1Warnings found while --fail-on-warning is enabled.
2Blocker, invalid arguments or operational error.
