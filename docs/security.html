TRUST

Security

StoreReady is designed around local artifact inspection and minimal Cloud data.

Local-first scanning

The open-source CLI inspects IPA/AAB artifacts locally. Cloud-enabled workflows currently send normalized findings rather than the application binary.

Secrets

Cloud API tokens should be provided through environment variables or CI secret stores. Do not commit tokens, signing certificates, App Store credentials or Play Console credentials to a repository.

Cloud alpha

The current Cloud authentication mechanism is intended for development and alpha testing. It will be replaced by scoped, revocable project tokens before public beta.

Responsible disclosure

If you discover a vulnerability, please avoid opening a public issue containing exploit details. Contact the project maintainer privately through the contact information associated with the GitHub repository.

Dependency and build checks

The CLI is built and tested on Linux and macOS in GitHub Actions. StoreReady Cloud separately validates Spring AOT compatibility and its Angular production build.
